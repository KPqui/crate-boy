HOW THE IMPORT WORKS

1. Rekordbox → Preferences → Advanced → Database → rekordbox xml: Imported Library = the crateboy_import file in OUT.

2. Sidebar → rekordbox xml → Playlists → Crate Boy …

3. Select all tracks → right-click → Import To Collection.

4. First time ever: do it with 2–3 tracks and check that cues, grid and key stayed. Only rating, comment and genre should change.
