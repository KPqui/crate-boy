# Crate Boy

KP's library rating tool, in two parts.

- **Phone app ("Pocket")** – open https://kpqui.github.io/crate-boy/ on the phone and "Add to home screen".
  Hold-to-talk notes and whole-set recordings. Sends them to the private inbox; the PC picks them up.
- **PC app** – put `desktop/CrateBoy.bat` in its own folder and double-click it. It downloads the newest
  version on every start, sets itself up the first time, and takes over data from older CrateBoy_v1.x folders.

Your legend, word list and rules are not in this public repo: they live in the private data repo.
